If you can’t see the background animation on this page, it means your browser/OS is effectively not rendering CSS animations in a visible way (or you have a “reduce motion” style setting in effect).

Notes:
- Try watching the pale blue/grey background for ~10 seconds.
- On desktop, try a hard refresh (Ctrl+F5) and/or a private window.
