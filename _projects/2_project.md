We develop **stochastic lattice / sheet-based cellular materials** to create lightweight structures with **controllable mechanical response**. The core idea is to use compact statistical descriptions (e.g., a target power spectral density / correlation structure) to generate 3D architectures that can be analysed (FEA) and manufactured (e.g., additive manufacturing).

This work includes papers with **Groth** and **Clayton**.

## Highlights
- **Continuum stochastic cellular materials:** methods to generate manufacturable stochastic architectures with tunable morphology.
- **Property tailoring:** spatial grading of structure statistics to control stiffness/strength directions and response.
- **Design → analysis → build loop:** generation, curvature/geometry characterisation, FEA, and printing.
